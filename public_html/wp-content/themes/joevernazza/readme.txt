== Description ==

Custom block theme for joevernazza.com.

* Design tokens (colors, Rubik variable font, fluid type scale, spacing) live in theme.json.
* Page sections ship as block patterns in the "Joe Vernazza" category; the "Home page" pattern builds a starter homepage.
* The "Reveal on scroll" Group and Separator style fades content in as it scrolls into view.
* Styles and scripts are compiled with Vite from /build_tools into assets/.

Requires the joevernazza must-use plugin, which provides SEO output, security hardening, analytics and the theme's custom blocks.
